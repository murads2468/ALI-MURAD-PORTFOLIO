# Ali Murad — Cloud Data Engineer Portfolio

## Run locally
1. Extract this ZIP.
2. Open the `ali_murad_portfolio_3d` folder.
3. Double-click `index.html` to open it in your browser.

## Before publishing
- Replace the ETL GitHub placeholder (`https://github.com/`) in `index.html` with your actual ETL project repository.
- Check your LinkedIn profile URL and email address.
- The site uses Google Fonts; an internet connection is needed to load those fonts. The rest of the website runs locally.

## Files
- `index.html` — website content
- `style.css` — responsive styling and 3D-inspired effects
- `script.js` — mobile navigation and reveal animations
