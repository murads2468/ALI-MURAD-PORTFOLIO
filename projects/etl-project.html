E-commerce ETL Pipeline

An end-to-end data engineering project that processes e-commerce sales data using Python, SQL Server and Power BI.

Project Overview

This project demonstrates an ETL workflow: Extracting raw data, cleaning and transforming it, loading it into SQL Server, and analyzing it through a Power BI dashboard.

Technologies Used

  • Python
  • Pandas
  • SQL Server
  • Power BI

ETL Process

1. Extract

Collected raw e-commerce transaction data.

2. Transform

Cleaned and transformed data using Python and Pandas.

3. Load

Loaded processed data into SQL Server.

4. Analyze

Created a Power BI dashboard to explore sales performance.

Project Results

  • Total Records: 524,878
  • Total Quantity: 5,572,420
  • Total Revenue: 10,642,110.80
  • Countries: 38
